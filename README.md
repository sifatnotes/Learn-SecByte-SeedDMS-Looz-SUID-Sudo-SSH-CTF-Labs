# Learn SecByte SeedDMS, Looz, SUID, Sudo & SSH CTF Labs

A focused collection of hands-on cybersecurity and CTF labs from Learn SecByte covering SeedDMS web reconnaissance, document-focused discovery, port scanning, Looz enumeration, SSH footholds, SUID privilege escalation, Sudo security, and Linux root-access paths.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical web reconnaissance and Linux security skills.

## Introduction

A practical security assessment often moves from reconnaissance and service discovery to application enumeration, foothold acquisition, local enumeration, and privilege escalation.

This repository organizes Learn SecByte labs around SeedDMS and web reconnaissance, port scanning, Looz discovery, SSH footholds, SUID binaries, Sudo permissions, and Linux privilege escalation.

## Learning Path

A practical sequence for this collection is:

1. Begin with **PortSweep Pro** for basic network reconnaissance.
2. Continue with **Seed Hunt Discovery**, **SeedDMS Web Trail**, and **SeedDMS Snapshot** for web application enumeration.
3. Use **DocTrail Recon Rush** and **SSH Foothold Hidden Web Clues** to connect web reconnaissance with foothold discovery.
4. Explore **Looz Local Enum** to understand local Linux enumeration after obtaining access.
5. Study **Looz Lock Login Root** and **Looz to Root** for controlled root-access scenarios.
6. Practice SUID privilege escalation with **SUID Sleuth Shell to Root** and **SUID Sleuth 3**.
7. Finish with **Sudo Sense Privilege Paths** for Sudo-based privilege-boundary analysis.

## How to Use the Labs

- Use all exercises only in authorized and controlled lab environments.
- Start with reconnaissance before attempting exploitation.
- Record discovered ports, services, application paths, and clues.
- Analyze web applications before attempting to obtain a foothold.
- Perform local enumeration only after gaining authorized lab access.
- Carefully inspect SUID binaries and Sudo permissions.
- Treat SSH credentials discovered in labs as lab-only information.
- Document each step, finding, and potential defensive mitigation.
- Never apply these techniques to systems without explicit authorization.
